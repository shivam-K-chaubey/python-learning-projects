## Etch-A-Sketch

A simple drawing application built using Python's Turtle graphics.

## Features

- Move the turtle forward using the **Space** key.
- Move backward using the **B** key.
- Rotate left using the **Up Arrow** key.
- Rotate right using the **Down Arrow** key.
- Clear the drawing and return to the starting position using the **C** key.

## Technologies Used

- Python
- Turtle Graphics

## Controls

| Key | Action |
|-----|--------|
| Space | Move Forward |
| B | Move Backward |
| Up Arrow | Turn Left |
| Down Arrow | Turn Right |
| C | Clear Screen and Reset |
