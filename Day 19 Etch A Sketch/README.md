# Day 19 - Etch A Sketch

## Description
A simple Etch A Sketch application built using Python's built-in Turtle module.

## Features
- Draw using the arrow keys
- Move the turtle in four directions
- Clear the screen and reset the turtle by pressing the `C` key

## Controls

| Key | Action |
|-----|--------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| C | Clear Screen |

## Technologies Used
- Python
- Turtle Graphics

## How to Run

```bash
python main.py
```

## Learning Objectives
- Turtle graphics
- Keyboard event handling
